Debugging Decision Tree

Wrong result
  -> OCR incomplete? inspect ocr/metadata.json and source-map.json
  -> Date wrong? inspect structured-resume.json experience evidence
  -> Requirement wrong? inspect eligibility.requirement_details
  -> Criterion wrong? inspect component_assessment.components
  -> Completeness wrong? inspect evidence_completeness_diagnostics
  -> Report differs? compare evaluation.json, CSV, HTML
  -> Cache stale? inspect run-manifest.json and .cache key inputs
